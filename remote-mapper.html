Map keys from any IR remote to keyboard keys and media controls. Turn your PC into a smart TV with an old remote.


universal-receiver

Hardware

The universal receiver is compatible with any standard IR remote. The IR receiver uses an Arduino Micro and a KY-022 IR sensor. The Arduino Micro acts as a USB keyboard, so once it is mapped to a remote it is plug and play with any PC. The mapping software generates custom C++ code and uploads it to the device using the Arduino CLI.


Software

The software was coded in Python. It uses PyQt6 for the UI. It communicates with the Arduino to display the IR remote codes. It can also compile and upload the mappings to the device. It supports up to eight remote key mappings, each of which can be mapped with up to four computer keys or media controls.
